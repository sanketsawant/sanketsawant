* # AI-Powered Handwritten Chess Notation Scanner

This repository contains the proof-of-concept and ongoing development for an AI-powered mobile application designed to digitise handwritten chess scoresheets.

## The Problem

In the UK and globally, thousands of competitive and club-level chess games are recorded on paper scoresheets. While major online platforms like `chess.com` and `lichess.org` offer powerful game analysis tools, they require the game's moves to be in a digital format (like PGN). The process of manually transcribing a handwritten scoresheet into a digital format is tedious, time-consuming, and prone to errors, meaning thousands of games are never properly analysed or preserved.

## The Solution

This project aims to solve that problem by creating a seamless "scan-to-analysis" workflow. The mobile application will allow a user to simply take a photo of their handwritten scoresheet. The app will then use a combination of technologies to instantly create a digital, analysable record of the game.

The proposed technical solution involves:
1.  **Optical Character Recognition (OCR):** To identify and extract the handwritten chess moves from the image.
2.  **Custom AI Agent:** To validate, correct, and format the extracted moves, ensuring they are legal and in the correct sequence.
3.  **Chess Engine Integration (Stockfish-based):** To perform an initial analysis of the game and provide immediate insights to the user.

This project was the subject of a productive consultation with a **Startup Cloud Specialist at Amazon Web Services (AWS) UK** in March 2025, which provided a clear path for its technical development using services like Amazon Textract and Comprehend.

## Technology Stack

* **Platform:** Flutter (for cross-platform deployment on iOS and Android)
* **AI / Machine Learning:** Python, TensorFlow Lite, Amazon Textract (for OCR)
* **Chess Logic:** Stockfish Engine Integration
